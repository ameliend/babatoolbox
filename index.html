LE PETIT INSTALL GUIDE

De la boîte à ton éditeur.

Pas besoin de terminal
  1. 01

    Télécharge ton outil

    Choisis un bouton ci-dessus. Garde le fichier .vsix tel quel : inutile de le décompresser.

    baba-select-0.2.1.vsix
  2. 02

    Ajoute-le à VS Code

    Ouvre le panneau Extensions, puis le menu …. Choisis Install from VSIX… (« Installer à partir du VSIX… ») et sélectionne ton fichier.

    ▦ Extensions …Install from VSIX…
  3. 03

    Recharge. Et crée.

    Recharge la fenêtre si VS Code le demande. Ouvre le dossier local de ton prototype et accorde-lui ta confiance si tu en connais le contenu.

    Tes outils sont prêts

Tu installes les deux ? Répète l’étape 2 pour le second fichier. Pour une mise à jour, installe simplement le nouveau VSIX.

ET MAINTENANT ?

Un geste, puis le suivant.

Ce composant-là.
Exactement celui-là.

  1. Garde ton aperçu et Codex ouverts.

    Utilise le navigateur intégré de VS Code. Pour un fichier HTML : clic droit → Open in Integrated Browser. Si tu as plusieurs chats, clique d’abord dans celui que tu souhaites utiliser.

  2. Active Baba Select et clique.

    Utilise « Baba Select » dans la barre d’état, en bas à droite de VS Code. Si une cible est demandée, choisis l’onglet d’aperçu existant. Un cadre jaune indique le survol, un cadre bleu la sélection.

  3. Ajuste la cible.

    « Parent ↑ » remonte du texte au bouton, puis à la carte. Une nouvelle sélection remplace la cible. Échap rend la navigation normale.

  4. Écris ta demande dans le même chat.

    Vérifie la présence de baba-select-context.md dans Codex, puis envoie toi-même ta demande.

« Réduis ce bouton et aligne-le avec le titre. »

Laisse une trace.
Ose la prochaine idée.

  1. Ouvre le bon dossier.
  2. Crée ton premier point de sauvegarde.

    Dans la barre latérale à gauche de VS Code, clique sur l’icône en forme de pendule avec une flèche pour ouvrir BABA versioning. Clique ensuite sur « Sauvegarder une version ». Donne-lui un nom, une description et, si tu veux, une miniature.

  3. Continue à explorer.

    Le dossier versions apparaît à la première sauvegarde réussie. Enregistrer ton fichier source ne crée pas de nouvelle version : tu choisis chaque étape à conserver.

  4. Reviens ou pars dans une autre direction.

    « Restaurer » remet le projet dans l’état choisi et conserve d’abord l’état actuel dans une version de sécurité. « Créer une variante » crée une copie indépendante.

Avant une restauration, mets en pause Codex et les autres outils qui écrivent dans le projet.
